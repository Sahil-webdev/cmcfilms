# CMC FILMS — Premium Wedding Photography and Cinematic Filmmaking Website

Design and build a complete, production-quality, highly polished, cinematic, fully responsive MERN-stack website for a premium wedding photography and filmmaking studio named:

CMC FILMS

The website must feel like a luxury editorial wedding magazine combined with a high-end cinematic film studio.

This should NOT look like a generic photography template, SaaS website, AI-generated landing page, or common agency website.

The final experience should feel emotional, artistic, sophisticated, cinematic, minimal, intimate, expensive, and memorable.

Use the provided reference images only for inspiration in terms of:

* editorial composition

* visual hierarchy

* large photography

* generous whitespace

* refined serif typography

* image-focused storytelling

* horizontally arranged categories

* muted luxury color palette

* immersive cinematic presentation

Do not directly clone any reference layout.

Create an original visual identity specifically for CMC FILMS.
